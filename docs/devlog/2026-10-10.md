## D4 系列 — vendor repair 评估与诊断收敛

- **D4-0（只读审计）**：MaintenanceTool = IFW 4.11.0；**无 repair/verify 命令**；
  `tools.licenseservice`（"Qt License Service 3.6.4"，3.6.4-202606181024）

  曾成功，当时提升正常）。
- **D4A**：`--unregister` exit 1（qtlicd 首次 ERROR 日志）；`.tmp` 被 truncate
  至 0 B；且产生「幻影文件」观察（CreateFileW 可打开、枚举/属性不可见）。
- **D4A-V（证伪，重要工程教训）**：**「幻影文件」 = ctypes FFI FALSE
  POSITIVE** —— probe 用 `ctypes.WinDLL` 未声明 prototype（`restype=c_long`
  = 32-bit）⇒ **HANDLE 被截断**，`CreateFileW` 失败返回值
  `0xFFFF…FFFF` 判读方向性错误（记为 SUCCESS）。宽度正确探针
  （`restype=wintypes.HANDLE`）全 API 一致证明 installations.ini **确实
  不存在**。**「文件系统过滤器虚拟化」条目予以撤回**；D4A/D2 的其余独立证据
  （4 次 register 记成功但无 durable file、unregister exit 1、.tmp truncate）
  不受影响。
  - **教训**：Windows x64 API 的 ctypes probe 必须显式声明 `restype/argtypes`；
    错误宽度的返回值比较会产生系统性错误结论。同类 probe 结论前先做
    「探针正向前能力对照」。
- **D4B（remove+install preflight，只读）**：裁定 **C — HOLD
