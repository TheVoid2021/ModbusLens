## 2. `75c59cd` — T034-B2.1-F1: relax test connection response classifier（21:48）

- **问题（Human 实测发现）**：Test Connection 分类器要求 2xx 响应的
  `choices[0].message.content` 为**非空字符串**，否则 `invalid_response`。
  但 Test Connection 是 **connectivity probe**（验证 endpoint 可达 + 凭据被
  接受 + 请求被理解），不是 answer-quality parser：thinking-first 模型在极小
  synthetic token budget（max_tokens=8）下可**合法**返回空 / null `content`
  （有时伴随填充的 `reasoning_content`）。
- **修复（`AiTestConnection.cpp`；请求形状不变）**：判别规则改为——
  2xx + body 为 JSON object + `choices` 为非空数组 + **任一 choice 的
  `message` 为 JSON object** ⇒ `connection_ok`。**不再**要求 content 类型、
  非空、role、reasoning_content 或最终文本；`reasoning_content` 永不读取、
  原始 body 永不记录 / 暴露。
- **测试（TEST FIRST，`test_ai_settings.cpp` +127）**：`f1_01`
  （reasoning-only 空 content → connection_ok；reasoning 文本与 raw body
  不得出现在 UI 文案）、`f1_02`（content null / 缺席 → connection_ok）、
  `f1_03`（多 choice 中任一合法 message → connection_ok）、`f1_06`
  （负向控制：非 2xx / 非 object / choices 缺失或空 / message 非 object
  → 仍 `invalid_response`）。
