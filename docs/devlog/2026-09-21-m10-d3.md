## W1. 实现要点

- **新增 `core/active/ProductWriteCapability.h`**：`kProductWrite06Supported` = 结构性产品能力常量
  （encoder + protocol/session + Controller atomic dispatch + evidence 集成四者齐备），
  **不是** runtime availability。
- **新增 Controller 原子操作** `confirmAndDispatchPreparedWrite(token)`：输入仅 opaque token；
  顺序固定 **final guards → consume → encode → start**；编码使用 **consume 前捕获**的不可变快照
  （因为 `PreparedWriteStore::confirm()` 会 `reset()` 清空 snapshot —— 读值不是 chain 中的一步，
  chain 仍是 guards→consume→encode→start）。
- **typed 结果** `PreparedDispatchResult{confirmationAccepted, dispatchAttempted, rejectedReason?,
  startResult?, localError?}`；**复用** `ActiveStartResult` / `TransportDisposition` / `ActiveTransportTerminal`。
- **提取共享 `startActiveDescriptor()`**（从 FC03 路径抽出）并由 FC03 回接 —— 读写共用同一
  in-flight 记账（pending / busy / BusyBecameTrue 失效 / clearSerialError / serialStatusChanged），
  **避免 write-only lifecycle**。
- **`ConfirmRejectReason += CapabilityUnavailable`**（原 6 值确实缺 capability 维度；最小扩展，
  未新建第二套 taxonomy）。
- **fake seam**：`setSubmissionAcceptedBytes(0)` 原本会**穿透到完整接受**；审计确认全仓
  **无任何 `0 = disable override` 依赖** ⇒ 直接定义 0 = zero-accept（attempt +1 / send +0 /
  NotSent / no pending / no terminal / 不进 ADU log）。
- **`write06Supported`**：只读 **CONSTANT** Q_PROPERTY（无 setter、无 NOTIFY）——能力是代码事实，
  没有真实 runtime 变化需要广播。

### X1. Source audit 结论（A/B/C/D）

```text

  外部事件（teardownSerialTransport / handleSerialTransportError / connectSerial /
  startActiveDescriptor）在 invalidate() 返回 true 时各自 announce。

C store.confirm() 确实不发 Qt signal ⇒ atomic API **显式 emit**。实测 full-accept 恰好 **+1** 次：
  consume 一次；随后 startActiveDescriptor 的 invalidate(BusyBecameTrue) 在 Consumed 代际是 no-op
  （store 只作用于 Prepared）⇒ 无第二次通知 —— 顺带独立复证「Consumed 不被 busy 覆写」。
D Dialog close 权威链：store state → Controller emit → QML 读 hasPreparedWrite（= state == Prepared）
  → confirmationDialog.close()。**与 transport 结果无关**。
```

### X4. 两层术语冻结（§14 口径更正）

```text
第一层 外部 context event ：Prepared → Invalidated(reason)
        reason ∈ {Disconnected, BusyBecameTrue, SessionChanged, SourceChanged, UserCancelled,
                  CapabilityUnavailable}，由事件写入且**永不改写**
第二层 事件后旧 token 调 atomic API ：**NotPrepared**
**禁止**表述为「atomic 的 disconnected guard 一定返回 NotConnected」

```
