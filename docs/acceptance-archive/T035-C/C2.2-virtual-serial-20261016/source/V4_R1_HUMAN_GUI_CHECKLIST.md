# V4_R1_HUMAN_GUI_CHECKLIST.md — Human 操作检查表

## 第 0 步（当前阻塞项）：准备测试 Device Profile

在 **ModbusLens 正常 GUI** 的「设备档案」页创建并**保存**一个测试档案（不修改现有 3 个档案）：

- 档案名建议：`v4-e2e-linear`
- 添加 1 个寄存器：
  - **功能码**：FC03（读保持寄存器）
  - **地址**：**49**（0-based / PDU）
  - **数量**：1
  - **数据类型**：UInt16
  - **Decoder**：**Linear**（显式选择，不要留 Unknown）
  - **Scale**：**0.01**
  - **Offset**：**0**
  - **Unit**：**s**
- 保存（必须持久化成功，重载后各项仍在）
- 记录档案显示名（Agent 将核验磁盘 JSON）

完成后告知 Agent（回复「Profile 已保存，名称 = ...」）。

## 第 1 步：正常 E2E（Agent 将配合启动）

Agent 会先启动外部从站（COM8），然后您操作 ModbusLens：

1. 启动 ModbusLens（Agent 提供隔离启动命令；勿加任何测试参数）
2. 打开「通信」工作区 → 选择 **COM7** → 波特率 **9600** → 连接
3. 打开「工程值」页面 → 选择刚保存的 `v4-e2e-linear` 档案
4. 选择寄存器 **FC03 @ 49**
5. 确认显示 **EngineeringReady**（就绪）
6. 点击「**读取一次**」**一次**（不要连点、不要轮询）
7. 预期大号数值显示：**12.34**　单位：**s**
8. **截图**保存（Agent 会告知保存路径）
9. 将「读取状态」行的文字告知 Agent（如「读取成功」/失败信息）

## 第 2–7 步：异常矩阵（Agent 会逐个切换从站模式）

每轮 Agent 重启从站为下一模式，您只需**再点一次「读取一次」**并反馈界面状态：

| 轮次 | 从站模式 | 预期界面行为 |
|---|---|---|
| E2 | CRC_ERROR | 读取失败/无效响应，**不得**出现新的 12.34 s |
| E3 | TIMEOUT | 超时错误状态（产品既有超时），不得无限等待 |
| E4 | WRONG_SLAVE | 拒绝（从站地址不匹配） |
| E5 | WRONG_FUNCTION | 拒绝（功能码不匹配） |
| E6 | EXCEPTION | 显示 Modbus 异常（代码 02），不得显示为成功 |
| E7 | FRAGMENTED | 累计响应被正确解析 → 12.34 s（分段压力测试，非标准 RTU 合规结论） |

每轮请告知：读取状态行文字 + 是否有新数值 + （可截图）。

## 第 8 步：收尾

断开串口连接 → 关闭 ModbusLens。Agent 将做测试后环境稳定性检查。

## 注意

- 不需要修改任何 Profile 数据之外的设置；不需要安装/卸载任何软件。
- 如任一步界面异常（卡死/崩溃/错误状态），立即告知，Agent 会保存证据并 STOP。
