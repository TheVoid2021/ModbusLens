## TEST#8 布局诊断原始输出（关键）

```
REGDIAG regUnitField ancestor-chain=<QQuickRowLayout> < <QQuickColumnLayout> < <QQuickItem> <
        <QQuickFlickable> < <ScrollView_QMLTYPE_39> < QQuickPopupItem < Dialog < <QQuickOverlay> < Main
REGDIAG container=QQuickFlickable  clip=1 contentHeight=627 contentY=0  ownHeight=513
REGDIAG container=ScrollView_39    clip=1 contentHeight=627             ownHeight=513
REGDIAG container=Dialog           clip=0 contentHeight=627             ownHeight=595
REGDIAG regUnitField in-dialog y=698.5 fieldEnabled=1
REGFAIL: regUnitField outside: x=257.5 y=698.5 w=729 h=32 win=1000x700
```

**推理**：字段位于 `ScrollView → Flickable`（`clip=1`），`contentHeight 627` − `viewport 513` = **可滚动 114 px**；
字段 `in-dialog y=698.5`、dialog 内容高 595 ⇒ **需滚动约 103.5 px** ⇒ **114 > 103.5 ⇒ 滚动后可达**；`fieldEnabled=1`。
